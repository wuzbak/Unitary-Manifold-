# Deltakit Community Fund

**Status at 2026-11-06:** 2026 applications closed. The fund page says 2027 awards will be quarterly; Q1 applications are expected to open in November 2026, with decisions in December and work beginning in January 2027. Award is **up to $4,000** plus mentorship.

## Strict scope

This fund supports work on Riverlane's open-source Deltakit quantum error-correction software. It is not a general quantum or physics grant. AxiomZero must first inspect the Deltakit repository, find an eligible unassigned issue or propose a fund-eligible one, and be prepared to make the contribution upstream.

## Proposed contribution process

1. Review current Deltakit issues and contributor guidance.
2. Choose a real, scoped QEC task that AxiomZero can complete competently.
3. Open or adopt the required issue and obtain the fund's eligibility label/confirmation.
4. Develop tests and a technical plan with Deltakit maintainers.
5. Apply for the Q1 2027 cohort only if the maintainers confirm the task is in-scope.

Do not represent AxiomZero's existing quantum ansatz tool as a QEC implementation or claim an existing Deltakit contribution unless it has been merged or otherwise evidenced.

**Official source:** [Deltakit Community Fund](https://unitary.foundation/community/deltakit_community_fund/).
