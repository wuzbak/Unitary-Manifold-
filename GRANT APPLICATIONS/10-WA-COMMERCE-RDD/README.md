# Washington Commerce Clean Energy R&D Demonstration

**Status at 2026-11-06:** the 2025–2027 Research, Development and Demonstration round is closed. Washington Commerce reported approximately $10 million in total program funding and an application deadline of Sep. 3, 2026. This is a next-cycle watch item, not an open application.

## Fit assessment

This program funds projects that create and test new clean-energy technologies aligned with Washington's energy strategy. AxiomZero is a Washington SPC, but its location alone does not make a project eligible. UM Geo Monitor's environmental data feeds do not constitute a clean-energy technology demonstration. A future proposal would need a real clean-energy use case, technical partner/user, measurable emissions or energy outcome, and match/allowable-cost analysis.

## Conditional future concept

If a future notice supports digital/AI tools for a defined clean-energy operational problem, consider a partner-led validation project using a relevant monitoring or analysis component. Define an energy baseline, emissions methodology, user workflow, and independent validation. Otherwise do not pursue.

## Next steps

- Subscribe to Commerce EPIC/Clean Energy Fund notices and FundHubWA.
- Request the 2025–27 RFA and read past eligibility, match, and cost rules only as preparation—not as terms for the next round.
- Seek a Washington energy-sector partner and a real test site before drafting.
- Recheck the next RFA for applicant types, funding limits, match, and schedule.
