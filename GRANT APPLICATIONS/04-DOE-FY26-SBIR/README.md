# DOE FY26 Fall SBIR/STTR Phase I

**Status at 2026-11-06:** active. The DOE application hub lists a **Dec. 16, 2026, 2 p.m. ET** deadline. The full request may not exceed **$300,000** (or $306,500 with the stated TABA amount). DOE indicates approximately 160 awards across the opportunity. The award is fixed-price with milestone payments: it is not unrestricted operating money.

## Decision: topic screen before any application work

This is a time-sensitive but **conditional** prospect. The public topic announcement describes energy and other technical areas. AxiomZero's physics or responsible-AI work is not automatically an energy R&D fit. Submit only if a current topic directly supports a feasible project and DOE's scope can be addressed with available technical expertise, data, and partners. Do not pitch the repository as an energy technology absent a specific technical deliverable and energy-sector use.

## Potential angle if an exact topic matches

Use a narrowly defined software component only if the chosen topic explicitly seeks it—for example, an auditable data/decision workflow for a listed energy challenge. State the actual DOE topic number, key requirement, baseline, validation data, test environment, and commercial application. If no exact match is found, record **NO-GO** and redirect effort to NOAA or NSF.

## 30-minute go/no-go checklist

1. Download the complete opportunity and all topic descriptions from the official hub.
2. Mark each mandatory topic requirement against an existing capability and identify gaps.
3. Confirm small-business ownership, size, PI, U.S. work, and SBIR/STTR eligibility.
4. Confirm the requested technology is eligible for SBIR and the proposed milestones can be verified for fixed-price payment.
5. Obtain a topic-specific reviewer and allowable-cost check.
6. Stop if fit depends on changing the actual purpose of the project or making unsupported performance claims.
