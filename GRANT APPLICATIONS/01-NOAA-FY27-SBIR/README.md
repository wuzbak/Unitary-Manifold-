# NOAA FY27 SBIR — Phase I

**Status at 2026-11-06:** upcoming notice; NOAA says FY27 cycle begins in Fall 2026 and targets releasing the NOFO Nov. 10–30, 2026. **Do not rely on an aggregator's date or amount until the notice is published.**

## Why consider it

UM Geophysical Monitor is listed in the product catalog as a TRL-5 prototype with 121 tests and integrations for selected public feeds. NOAA's past topics have included weather, water, climate, coastal resilience, hazards, AI, and data/cloud computing. This is the closest currently identified federal program to that existing environmental-data software. The NOAA topic list and award terms change each competition.

## Proposed project angle — conditional

**Working title:** *Evidence-Traceable Environmental Event Monitoring for a NOAA Mission Topic.*

Select one FY27 topic only after release. A possible research question is whether a bounded, provenance-preserving data pipeline can improve an explicitly measurable NOAA-relevant monitoring or decision-support task. Specify a baseline, data sources and licensing, false-positive/false-negative costs, latency/availability target, and independent evaluation. Do not describe the current prototype as an operational warning or forecasting system.

## Fit and gates

- NOAA's applicant page describes eligibility for American-owned, independently operated, for-profit U.S. small businesses with fewer than 500 employees including affiliates; the PI must be employed at least 51% by the firm, and U.S. work-share rules apply. Verify the FY27 notice.
- NOAA currently lists Phase I awards up to $190,000 for up to 6 months and Phase II up to $690,000 for up to 24 months; these are current-program reference figures, **not a promise for FY27**.
- Proceed only if a published FY27 topic directly matches an actual Geo Monitor capability and there is a commercialization path beyond the agency.
- A NOAA-aligned pilot/data expert would materially strengthen the plan; do not name a partner until confirmed.

## Draft abstract

AxiomZero Technologies & Consulting, SPC proposes to investigate a software method for [NOAA topic/problem], using authorized public data and an auditable record of source, timestamp, transformation, and uncertainty. The Phase I work will define representative scenarios with a domain reviewer, implement a bounded prototype, and compare it with [named baseline] on pre-registered metrics: [metric], [metric], and [metric]. The project will report failure cases and limitations as well as successes. Phase I will determine technical feasibility and commercial potential; it will not claim operational NOAA performance or replace official data/services.

## Work plan (six months; revise to the NOFO)

1. Confirm topic, users, data rights, success thresholds, and baseline.
2. Establish test fixtures and a reproducible evaluation protocol.
3. Implement only the topic-relevant prototype capability.
4. Evaluate on held-out scenarios and document failures.
5. Conduct customer discovery and produce a Phase II/commercialization decision.
