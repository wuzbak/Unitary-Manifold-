# UM-SOS Frontend

Static frontend for prediction exploration, admissions visibility, and governance lane classification.

## Local usage

Open `10-UM-SOS/frontend/index.html` with any static server (or via GitHub Pages artifact).

## Data sources

- Preferred: `/api/v1/*` endpoints
- Fallback static mode:
  - `../registry/predictions.json`
  - `../graph/dag.json`
