The Problem with Current Election Auditing

Election records are difficult for observers to recompute unless CVRs, manifests, signed logs, custody records, audit samples, and results are published in consistent formats.

EIGE v22 is audit support, not a vote-counting system.

EIGE v22 helps officials publish verifiable artifacts: Merkle logs, signed tree heads, witness cosignatures, reconciliation outputs, RLA support records, custody events, and a standalone verifier.

What EIGE Checks

AttackDetection Mechanism
Logged-record insertion or deletion after publicationMerkle consistency and signed tree heads
Unauthorized signer or stale keyEd25519 registry, role, and time checks
Split view of the public logWitness cosignatures and equivocation evidence
Count or manifest mismatchCanvass reconciliation codes and explanations
Outcome-changing tabulation error in sampled ballotsRisk-limiting audit calculations and escalation
Paper custody gapCustody ledger with two-official sign-offs
Turnout or residual-vote outlierRobust screen labelled as an investigation lead

Publication Bundle Architecture

[PUBLIC VERIFIER]
Receives: publication bundle and registry
Reports: verified, failed, warning, or not_checked
▲ signed tree heads and witness cosignatures
[BULLETIN BOARD AND WITNESSES]
Consistency checks and split-view detection
▲ Merkle log, custody events, reconciliation, audit samples
[ELECTION OFFICE PUBLICATION BUNDLE]
CVRs, manifest, results, registry, log, heads
CVR redaction follows jurisdiction policy

Quick Start

# Install
pip install -r requirements.txt

# Run tests
python -m pytest tests/ -q

# End-to-end synthetic election demo
python run_demo.py

# Verify a publication bundle
python -m eige.verify bundle path/to/bundle --audience voter

A Note on Scope

EIGE v22 is an adjacent governance application. It does not rely on physics claims for election security.

The v21 physics-framed security mechanisms are retracted. v22 uses standard signed logs, public verification, reconciliation, custody records, and RLA support.
