About This Project

Unitary Manifold

What This Is

A 5-dimensional Kaluza-Klein physics framework proposing that thermodynamic irreversibility is a geometric consequence of a compact fifth dimension. The framework has 590 computational pillars, 49,850+ passing tests, 274 Lean4 theorems, and a falsifiable prediction awaiting LiteBIRD (~2032).

The Unitary Pentad is an independent governance framework borrowing the mathematical structure of the physics — not itself a physics claim.
