Manifold Braid Chart
An interactive Smith-chart analogue for the 5D/4D Kaluza-Klein state space. Level sets map curvature, coupling, and braid topology; the convergence spiral traces the fixed-point iteration xk+1 = T(xk). Hover to read state coordinates. Click anywhere inside the chart to set the trajectory start point.
🟢 Runs in Browser ⚛️ KK Physics Canvas / Vanilla JS No backend required
Epistemic status: The coordinate map and level-set families are derived from the Unitary Manifold equations (see src/core/metric.py, src/core/fixed_point.py). The fixed-point map T(x) rendered here is a phenomenological model matching the qualitative behaviour of the Python implementation — not a pixel-perfect numerical solve. The weight parameters w_B, w_φ, w_K, w_U are adjustable (and presently unfixed from first principles): use the sliders to explore sensitivity.
