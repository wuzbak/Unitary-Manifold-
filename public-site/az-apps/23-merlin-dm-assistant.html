Product 23 · v1.1.0 · Offline-first

Merlin DM Guide & Player Assistant

Tabletop campaign operating surface for Dungeons & Dragons 5e/5.5e with separate DM and player dashboards, invite-code joins, character import, campaign trackers, encounter tools, and Merlin-assisted table guidance.

Core capabilities

  • DM/player split dashboards with synchronized campaign state
  • Invite-code campaign joins and player import flow
  • XP, gold, treasure, inventory, map, NPC, and encounter tracking
  • Grounded image-brief generation and DM image pushes
  • Standalone player mode with no live campaign dependency

Integration posture

Product 23 exposes governed service interfaces for campaign state, rules context, and Merlin-assisted table workflows. Public documentation remains capability-level; operational interface details stay in developer-controlled repository docs.

Run locally

cd 12-AZ-IP/23-merlin-dm-assistant
pip install -r requirements.txt
python run.py --port 8033

UI: http://127.0.0.1:8033/
