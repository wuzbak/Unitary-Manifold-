NFC Module

Web NFC (NDEFReader)

IDLE
Reads a real induction-coupled tag through the device's NFC radio: the tag's serial number and its NDEF records. It only answers while a tag is physically present, so this is an event, not a stream. Requires Chrome on Android over a secure context — other browsers report that they expose no Web NFC.

Ultrasonic Fingerprint Sensor

Platform authenticator (WebAuthn)

IDLE
The under-display sensor is reachable only as a platform authenticator: the page can ask the OS to use it, but the ridge map itself is never exposed to the page — only a pass/fail credential result. Enrolling writes a real passkey bound to this hostname; no biometric data ever leaves the device, and the credential can be removed from the device's passkey settings at any time.

SDAM — Software-Defined Acoustic Modem

Real sound-wave data link

IDLE
This encoder genuinely plays audio through the device speaker and genuinely listens through the microphone — it is a real (if simple) single-tone-per-nibble FSK scheme over the Web Audio API, not a math illustration. It is far simpler than the full OFDM link in the native 12-AZ-IP/14-sdam product: treat it as a working proof of an air-gapped acoustic channel, tested loopback on one device or between two devices placed near each other.
Base frequency
1760 Hz (A6) · 125 Hz/step, 16 tones
Symbol duration
120 ms/nibble + 30 ms gap
Encoding
UTF-8 byte → 2 nibbles → 2 tones, start/stop sentinel tones
Decode method
Live FFT (AnalyserNode) peak-bin matching, 48000 Hz
