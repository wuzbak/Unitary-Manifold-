Download and install AxiomZero

These are test builds, not production-certified releases. Download only published assets from this repository. If a version is absent, it has not been published; the source checkout is not an installer.

Product 45: Windows x64

The installer includes a local Qwen3-4B model distributed in companion files. The EXE alone is insufficient. Setup never downloads missing files.

Open Windows test releases

  1. Download the release's versioned AxiomZero-PC-Suite-*-download.ps1 helper, or download every installer, offline manifest, model part and SHA256SUMS.txt manually into one folder.
  2. Read the helper before running it in Windows PowerShell. It asks before downloading the multi-gigabyte kit and verifies its files; it does not run the installer or install a model automatically. Follow the exact command in the release's Product README.
  3. Keep the complete kit together and run its EXE from the extracted local folder, not inside a ZIP. Missing or corrupted companion files must be replaced from the same release.

An optional larger model can be imported into an operator-managed local Ollama installation. Choose it explicitly in the research control plane. This does not replace the bundled model or authenticate third-party weights, and requires substantially more memory and disk.

Product 46: Android

Requires Android 8.0 or later on a 64-bit ARM device. The APK does not bundle model weights; local retrieval remains available without a model download.

Open Android test releases

  1. Download app-debug.apk and SHA256SUMS.txt from the same published release.
  2. Verify the APK before installing. In PowerShell, Get-FileHash .\app-debug.apk -Algorithm SHA256 must match the checksum. On Linux, run sha256sum --check SHA256SUMS.txt in the download folder.
  3. Transfer the APK to your test phone and explicitly allow installation from that source, or use adb install app-debug.apk on a connected device with authorized USB debugging. Never uninstall an existing copy before exporting notes you need to retain.

For optional on-device reasoning, use the app's Local AI tab to explicitly download its verified Qwen3.5-2B model (about 1.28 GB), or import the exact pinned GGUF from a file you already own. This does not upload your evidence. Inference requires at least 4 GiB RAM and matching local evidence; the transfer requires 1.75 GiB free app storage. All generated answers remain UNVERIFIED.

The APK is debug-signed. A build signed with a different debug key cannot update an existing install; uninstalling clears private app data. Read the release notes for supported Android versions, model controls and the exact scope of runtime verification. Physical-device performance is not guaranteed by emulator checks.
