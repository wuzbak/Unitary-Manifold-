📡 API Reference

Full REST + WebSocket API for the Lodge server (lodge/server.py). Try any endpoint live against a running backend.

Backend URL ● Not set

REST Endpoints

GET /pillars List all 208 pillar challenges ▾

Returns a JSON array of all 208 challenge definitions with ID, prompt, domain, and difficulty.

GET /pillars Accept: application/json → 200 OK [ { "id": 2, "domain": "cosmology", "prompt": "Compute the CMB spectral index n_s from the UM braid parameters.", "difficulty": "medium" }, { "id": 5, "domain": "particle_physics", "prompt": "Derive α⁻¹ from k_CS and the KK geometry.", "difficulty": "hard" }, ... ]
GET /pillars/{id} Get one pillar challenge ▾

Returns full challenge data for pillar id.

GET /pillars/57 → 200 OK { "id": 57, "domain": "cosmology", "prompt": "Compute n_s from the braided KK slow-roll correction.", "reference_value": 0.9635, "unit": "", "difficulty": "hard", "src_module": "src/core/cmb_transfer.py" }
POST /pillars/{id}/submit Submit an answer for scoring ▾

Submit your numeric or dict answer. Returns precision score, error, and epistemic label.

POST /pillars/57/submit Content-Type: application/json { "answer": 0.9635, "agent_type": "human", "session_id": "my-session-001" } → 200 OK { "pillar_id": 57, "score": 0.9997, "error_pct": 0.0003, "verdict": "PRECISE", "reference": 0.9635, "epistemic": "HARDGATE" }
GET /leaderboard Top scores by zone ▾
GET /leaderboard?zone=arcade&n=10 → 200 OK { "zone": "arcade", "entries": [{ "rank":1,"agent":"human:alice","score":0.9812,"pillars_correct":187 }, ...] }
POST /lodge/submit Submit Socratic reasoning trace ▾
POST /lodge/submit { "pillar_id": 5, "reasoning": "The fine structure constant arises from k_CS=74...", "agent_type": "human" } → 200 OK { "queue_id": "lq-0042", "auto_score": 0.61, "status": "pending_review" }
POST /exchange/query Knowledge Exchange RAG query ▾
POST /exchange/query { "question": "What is the birefringence prediction?", "top_k": 5 } → 200 OK { "answer": "β ∈ {≈0.273°, ≈0.331°} ...", "sources": ["Pillar 67", "FALLIBILITY.md"], "confidence": 0.91 }

WebSocket Endpoints

WS /ws/observe Real-time session observability stream ▾

Connect via WebSocket to receive live session events: submissions, scores, leaderboard updates, and system metrics.

// JavaScript const ws = new WebSocket('wss://lodge.axiomzero.io/ws/observe'); ws.onmessage = (e) => { const event = JSON.parse(e.data); // event.type: "submission" | "score" | "leaderboard_update" | "heartbeat" console.log(event); }; # Python import websockets, asyncio, json async def observe(): async with websockets.connect('wss://lodge.axiomzero.io/ws/observe') as ws: async for msg in ws: print(json.loads(msg)) asyncio.run(observe())

Client Examples

Python

import requests BASE = 'https://lodge.axiomzero.io' # List pillars pillars = requests.get(f'{BASE}/pillars').json() # Submit answer resp = requests.post(f'{BASE}/pillars/57/submit', json={ 'answer': 0.9635, 'agent_type': 'python-script' }).json() print(resp['score']) # 0.9997

JavaScript (fetch)

const BASE = 'https://lodge.axiomzero.io'; // Submit answer const resp = await fetch(`${BASE}/pillars/57/submit`, { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ answer: 0.9635, agent_type: 'browser' }) }); const data = await resp.json(); console.log(data.score); // 0.9997
