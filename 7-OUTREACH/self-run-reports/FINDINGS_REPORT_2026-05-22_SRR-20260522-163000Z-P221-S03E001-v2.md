- **Antisymmetry of field strength:** `F_{μν} + F_{νμ} = 0` symbolically.
- **Ricci decomposition:** The 4D Ricci scalar, Maxwell kinetic term, and dilaton

  coupling all verified symbolically.
- **Numerical consistency:** Symbolic expressions evaluated at concrete field values agree
  with the direct numerical implementation in `src/core/metric.py`.

This matters because numerical tests can mask algebraic errors (e.g., a wrong
coefficient that happens to be consistent at a chosen test point). The SymPy layer
catches those. All 55 pass.

interface specification, the parity-checking logic, and the routing decision engine

Lean4 is installed via `elan` (a Lean version manager), not pip. In this sandbox, the
Lean4 binary is not present. The `src/core/formal_proof_hardening.py` module handles
this via a documented fallback: when Lean4 is absent, the module operates in pure-Python
verification mode, which checks the same logical structure using Python-level assertions.
`test_formal_proof_hardening.py` (4 tests) all pass in this mode.

The formal Lean4 proofs themselves exist as `.lean` files in the `lean4/` directory and
are verified separately in environments with Lean4 installed (i.e., the developer's local
machine and CI environments with elan configured). They are not counted in this report's
test totals.
