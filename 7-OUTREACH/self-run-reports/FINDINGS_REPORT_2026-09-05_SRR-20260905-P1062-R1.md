carried a v20.1 header and older routing architecture language while the live

ledger with active decision procedures, not the canonical current sprint/status
surface.

### F-02 — Live status JSON pipeline contained stale observational verdicts

`/home/runner/work/Unitary-Manifold-/Unitary-Manifold-/9-INFRASTRUCTURE/generate_live_status.py`
and the generated `/home/runner/work/Unitary-Manifold-/Unitary-Manifold-/9-INFRASTRUCTURE/um_live_status.json`

`w_a` lanes.

**Remediation:** the live status pipeline now reflects the current honest state:

- `w_a` remains **HIGH_TENSION**
- `r` remains **HIGH_TENSION**
- the current open-lane set is exported explicitly
- validation now fails if those machine-readable lanes drift again

### F-03 — Radion/evolution documentation overstated active stabilization or open gaps

`/home/runner/work/Unitary-Manifold-/Unitary-Manifold-/src/core/evolution.py`
described stabilization too strongly even though it is optional and disabled by
default, and it still described older ADM / KK-irreversibility sub-gaps as open.

**Remediation:** the file now states clearly that:

- stabilization is available but disabled by default,
- the ADM/BSSN lapse sub-gap was closed by Pillar 434,
- KK truncation does not negate irreversibility because the zero mode is a
  lower bound on full-tower entropy production.

### F-04 — Selected Lean files blurred the line between theorem and status marker

Several Lean surfaces used proxy arithmetic or trivial status markers in ways
that could be read too strongly.

**Remediation:** explicit scope notes were added to the audited files so that
proxy arithmetic, scaffolding, and status markers are labelled as such.

### F-05 — Pillar 833 mixed a 0.2% implemented bound with older 0.1% wording

The radion two-loop audit package used a 0.2% implemented threshold while older
text still spoke as if the result were sub-0.1%.

**Remediation:** the module now states the actual 0.139% value and exports an
explicit curvature proxy plus a flag that distinguishes the legacy gradient
proxy from an exact Hessian proof.
