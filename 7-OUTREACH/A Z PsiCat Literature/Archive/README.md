# Preserved Book Sources

Markdown file per book in [`Books/`](../Books/). No book has been merged with
another book.

On **2026-11-05**, Books 53-58 were individually assembled at their existing
main filenames. Their original front matter and manuscript sections, together
with Book 53's former `FULL` edition, are preserved **byte-for-byte** in
[`2026-11-05-books-53-58/`](2026-11-05-books-53-58/).
The [preservation manifest](2026-11-05-books-53-58/preservation_manifest.json)
records each original repository path, archived filename, byte count, and
SHA-256 checksum. All 58 original source files are retained.

The archive is a frozen preservation record, **not a second maintained edition**.
Its old instructions, filenames, publication-era claims, and reading-copy notes
are intentionally unchanged. For reading, citation, corrections, and future
edits, use the complete volumes above. Each volume has internal contents links;
its original prose, evidence caveats, citations, credits, and appendices remain
with that book. Only assembly/navigation instructions and heading nesting were
adapted.

The existing opt-in editorial retrieval loader reads the maintained
`Books/`, `Articles/`, and `Releases/` directories, not this archive. Preservation
copies therefore do not create duplicate retrieval sources.
