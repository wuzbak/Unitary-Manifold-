You cannot un-break an egg. You remember yesterday but not tomorrow. Stars die but never undie. Your coffee cools and never spontaneously reheats.

These are not separate phenomena. They are all consequences of the same thing: the arrow of time. And for the last 150 years, the best scientific answer to "why does time run forward?" has been: *probability*. The universe started in an extraordinarily unlikely low-entropy state. Disorder increases because there are astronomically more ways for a system to be disordered than ordered. Given enough time, nearly anything that can happen, will — and nearly everything that can happen involves more disorder, not less.

This explanation is mathematically consistent. It is experimentally confirmed. And it is, in a very specific sense, unsatisfying — because it replaces one mystery (why does time flow forward?) with a harder one: why did the universe start in such a special, improbably ordered state?

The Unitary Manifold takes a different position: the statistical answer is correct as an *effective* description but wrong as a *fundamental* one. The real reason time runs forward is not probability. It is geometry.
