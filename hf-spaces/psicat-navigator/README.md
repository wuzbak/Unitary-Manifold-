# PsiCat Navigator — HuggingFace Space

**AxiomZero Technologies & Consulting, SPC**

The sovereign AI navigator for the Unitary Manifold Framework. This Space runs on HuggingFace and provides:

- **Chat** — Talk to PsiCat (powered by Llama-3.1-8B-Instruct via HF Inference API)
- **Repo Status** — Live status from the GitHub repository (wuzbak/Unitary-Manifold-)
- **About** — Framework overview, three layers, products
- **Products** — Portal linking to all AxiomZero product Spaces

## Configuration

Set the following secret in the Space settings:
- `HUGGINGFACE_API_KEY` — Your HuggingFace API token

## Design

AxiomZero Design System:
- Deep charcoal base (#0B0F13)
- Amber (#FF9F00) for telemetry
- Ice Blue/Teal (#4DD0E1) for framework
- JetBrains Mono for headings, Inter for body
- Hard-angled containers, no rounded corners

## Deploy

1. Create a new Space on HuggingFace: https://huggingface.co/new-space
2. Name: `psicat-navigator`
3. SDK: Gradio
4. Set secret: `HUGGINGFACE_API_KEY`
5. Upload files from this folder
