## Deterministic Environment (Lockfile)

The file `requirements.lock` pins every dependency — including all transitive
dependencies — to exact version numbers.  This file was generated by:

```bash
pip-compile requirements.txt --output-file=requirements.lock
```

and is regenerated on every sprint.  Using `requirements.lock` guarantees
bit-reproducible numerical results regardless of when you clone the repository
or what other packages are installed on your system.

If you prefer the loose version bounds (for integration testing):

```bash
pip install -r requirements.txt
```

## What "Reproducible" Means Here

**Bit-level reproducibility:** The same test result (pass/fail) is guaranteed
on any platform with Python 3.12 and the locked dependencies. Floating-point
values may vary at the 15th significant digit due to CPU FPU differences;
all tolerances are set conservatively to avoid this.

**Numerical reproducibility:** All physics calculations use deterministic
algorithms (no PRNG seeding issues, no GPU non-determinism). JAX GPU
acceleration is optional and disabled in CI.

**Semantic reproducibility:** Every prediction is sourced from a named module
constant with a corresponding test. Changing a prediction requires changing
the source module and passing the mutation gate.
