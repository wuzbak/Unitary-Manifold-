# ARCHIVE — Superseded and Inactive Materials

This folder is for material preserved for provenance but not used as the current evaluation surface.

## What belongs here

- Superseded reviews, audits, and operational packets that are no longer canonical.
- Inactive experiments, retired hypotheses, and compatibility notes.
- Old generated outputs that should remain available but should not guide current review.

- [`../README.md`](../README.md) — public front door and quick navigation.

## Rule

Archived files are evidence, not authority. If an archived snapshot conflicts with a canonical file, the canonical file wins.
